# Стенд OpenCart 4.1.x для пакета `4.x`

Docker-стенд для разработки и приёмки модуля под OpenCart 4.1.x: PHP 8.3 + Apache, OpenCart 4.1.0.4, MariaDB 11 и mock-сервер API ApiShip.

## Запуск

```bash
make oc4-up          # сборка образа (скачивает OpenCart с GitHub), установка магазина
make oc4-logs        # дождаться строки "OpenCart installed"
```

| Что | Адрес | Доступ |
|---|---|---|
| Магазин | http://localhost:8080/ | — |
| Админка | http://localhost:8080/admin/ | admin / admin1234 |
| Mock API ApiShip | http://localhost:8085/v1/ | любой непустой токен |

Модуль на стенде ходит в mock API: в `config.php` и `admin/config.php` при установке добавляется `define('APISHIP_API_URL', 'http://mock-api:8085/v1/');`. Чтобы проверить работу с боевым API, удалите эту строку из обоих файлов (или уберите переменную `APISHIP_API_URL` в `docker-compose.yml` и пересоздайте стенд).

## Установка модуля

1. `make build-oc4` — собирает `apiship.ocmod.zip` в корне репозитория. Имя файла менять нельзя: установщик OC4 создаёт папку `extension/<имя архива>/`.
2. Админка → Расширения → Установщик → загрузить `apiship.ocmod.zip` → «Установить» (зелёная кнопка).
3. Расширения → Расширения → тип «Доставка» → ApiShip → «Установить», затем «Редактировать».
4. В настройках: токен (для mock API — любой), валюта/вес/длина, адрес отправления, контакты, статусы заказов; вкладка «Параметры отгрузки» — включить курьера или привоз на склад хотя бы у одной службы; сохранить; статус «Включено».

Быстрая проверка правок без переустановки: `make oc4-sync` копирует `4.x/` поверх установленного модуля и сбрасывает кеш шаблонов.

## Сценарий приёмки

1. Витрина: товар в корзину → Оформление → адрес доставки (страна Россия, город Москва) → «Выбрать» способ доставки: в модалке есть варианты ApiShip (ПВЗ и курьер), у ПВЗ ссылка «выбрать ПВЗ» открывает карту, после выбора точки вариант меняется на конкретный ПВЗ. Без выбранного ПВЗ «Продолжить» возвращает ошибку.
2. Оформить заказ.
3. Админка → Заказы → заказ → вкладка «ApiShip»: параметры места заполнены, «Создать заказ в ApiShip» → статус и трек-ссылка появились, кнопки «Ярлык» и «Акт» отдают ссылки на файлы.
4. Список заказов: отметить заказ → кнопки ярлыка/акта в шапке.
5. Cron: `curl "http://localhost:8080/index.php?route=extension/apiship/shipping/apiship.export_orders&key=<ключ>"` и `...apiship.import_orders&key=<ключ>` (ключ — в настройках модуля).

## Mock API

`mock-api/server.py` — HTTP-сервер на стандартной библиотеке Python. Возвращает две службы доставки (СДЭК, Boxberry), шесть точек в Москве, тарифы до ПВЗ и до двери, хранит созданные заказы в памяти (статусы, отмена, ярлыки, акты). Данные сбрасываются при перезапуске контейнера.

## Остановка

```bash
make oc4-down        # удаляет контейнеры и тома (БД и файлы магазина)
```
